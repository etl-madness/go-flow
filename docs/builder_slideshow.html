Architecture & Philosophy

What is Flow Builder Doing?

A zero-dependency local web studio served directly from the Go binary

💡 The Core Purpose

Flow combines the speed and simplicity of declarative XML pipelines with the ergonomics of a modern visual DAG editor. Running flow -builder starts an embedded lightweight web server backed by flow_builder.db.

🏗️ 3-Tier Visual Architecture

  • Left Component Palette: Drag-and-drop primitives categorized by lifecycle: Pipeline Setup, Control Flow, Database & SQL, Key-Value Stores, and Templates.
  • Center Interactive Canvas: A 4-stage pipeline hierarchy (Variables, Databases, Preflight Checks, Pipeline Flow) with instant reordering and editing.
  • Right Live XML Preview: True bidirectional synchronization: visual modifications immediately regenerate valid, Git-friendly XML.

🚀 Zero Runtimes, Zero Bloat

Unlike Airflow (requiring Python environments, Celery, Redis) or SSIS (heavy server runtimes), Flow runs anywhere as a standalone binary with zero external dependencies.

🖥️ Launching the Studio

# Start builder on default ephemeral port:

  • Filter Input: Quickly locate step types with instant keyword matching.
Database Management

Database Connection Configuration

Multi-engine driver abstraction, dynamic secrets, and connection pool tuning
🔍 Click to zoom
Modal: Edit <database> Connection Pool Builder_VS_Dark_Edit_Database_Connection.png

🎯 What It's Doing

Configuring the log_db database connection pool. Flow abstracts cross-dialect SQL queries, dynamic parameters, and secret interpolation seamlessly.

✨ Key Features Highlighted

  • Multi-Engine Support: Connects to Microsoft SQL Server, PostgreSQL, MySQL, SQLite, Oracle, and Key-Value stores.
  • Dynamic Secret Interpolation: The DSN uses {{log_db_cs}}, allowing secrets to be resolved up to 3 levels deep from environment overrides or CLI flags—preventing hardcoded credentials in source control.
  • Workload Profiles: Pre-set tuning profiles for oltp, bulk, analytics, and batch.
  • Enterprise Pool Controls: Max Open Conns (25), Max Idle Conns (10), and Max Lifetime (300s).
  • Custom Attributes: Add key-value attributes such as descriptions, timeouts, or custom driver parameters.

Summary & Reference

Flow Engine & Builder Quick Reference

Ready to conquer your data pipelines with Go-powered speed

🏆 Summary of What Flow Builder Delivers

  • Zero Dependencies: Single Go binary with embedded HTMX UI and SQLite storage.
  • Declarative XML Pipelines: Clean version-controllable schemas compatible with CI/CD.
  • Native Dialect Translation: SQL Server, Postgres, MySQL, Oracle, SQLite, and KV stores.
  • Interactive Testing: Isolated preflight validation runs and live console telemetry.
  • Enterprise Observability: Automatic audit logging to pipeline_runs and pipeline_events.

⌨️ Essential CLI Commands

# 1. Launch Visual Web Studio
flow -builder -builder-port 8080

# 2. Run Preflight validation checks only
flow -file pipeline.xml -preflight

# 3. Execute with pre-baked options profile
flow -file pipeline.xml -options options.xml

# 4. Run with runtime variable overrides
flow -file pipeline.xml -vars "TargetTable=prod_orders"
