                            ⚠️ SQLite Storage Maintenance
                            Danger Zone
                        

                        
Reset the embedded visual builder SQLite database (flow_builder.db) to initial factory defaults.

                    

                    
                

                

                    
What happens when you purge the database?

                    
    
                        
  • All draft pipeline scripts and visual node trees are permanently cleared.
    • 
                        
  • Config overrides (CONFIG.xml) and options files (options.xml) are reset to factory templates.
    • 
                        
  • All saved database connection profiles are reset.
    • 
                        
  • Auto-increment sequence counters are reset and a fresh default pipeline script is seeded.
